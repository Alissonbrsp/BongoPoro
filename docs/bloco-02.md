# Bloco 02 — Motor de animação inicial

Execute a partir da raiz do projeto com o ambiente virtual ativo:

```bash
python src/main.py
```

Teste repouso, teclado, mouse e ambos simultaneamente dentro da janela. A piscada ocorre a cada quatro segundos, somente em repouso. ESC encerra. Os eventos são locais à janela; o programa não registra o conteúdo digitado nem grava áudio.

Sem PNGs oficiais, aparece um círculo temporário e o nome BUSTER. Os sprites devem ser adicionados a assets/sprites/. A captura global será implementada em etapa posterior. Protótipo ainda aguarda validação no Kali e no Windows.
